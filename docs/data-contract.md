# 业务资料口径

points 为按原始坐标 x 递增的 [x,y] 观测，不保证等距或相同终点；所有曲线使用同一声明单位。同 specimen 为同一试件重复测量，同 batch 有共同制备条件，treatment 是工艺标签而非随机分配承诺。end_reason 区分 complete 与 early_stop，不包含未记录的终点。对齐映射须单调、记录参照与适用支撑；没有观测的尾部不能视为 y=0。统计结论应说明是总体关联比较还是有额外设计依据的处理效应，并保留相位与幅度定义。

小样本用于手工核对字段和边界；历史样本只扩展观测量，不保证任何推断、优化或方案一定成立。实际分析应允许信息不足或条件冲突。

工艺比较分析（GET /comparison）在本契约之上额外遵守：批次为推断单位、试件重复先在试件内平均；对齐只允许工艺臂级、有上限的 x 平移并始终保留无对齐结果；严格共同支撑之外不置零、不外推；条件不满足时显式停止。完整口径见 docs/analysis.md。
